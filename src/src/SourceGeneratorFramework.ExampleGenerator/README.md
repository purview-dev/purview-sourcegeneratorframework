# SourceGeneratorFramework.ExampleGenerator

Reference implementation of an incremental C# source generator built with `Purview.SourceGeneratorFramework`. This project is **not** published as a NuGet package; it demonstrates how to build a realistic generator end-to-end.

## What it does

`ServiceRegistrationGenerator` scans for types decorated with `[GenerateService]` and emits three things:

1. **Post-initialization source**  
   - `GenerateServiceAttribute`  
   - `ServiceLifetime` enum (`Singleton`, `Scoped`, `Transient`)  

2. **Service registration extension**  
   `Purview.SourceGeneratorFramework.Examples.ServiceCollectionExtensions.AddExampleServices(this IServiceCollection)` registers every attributed implementation using the correct `AddSingleton`, `AddScoped`, or `AddTransient` call from `Microsoft.Extensions.DependencyInjection`.

3. **Optional metadata class**  
   `Purview.SourceGeneratorFramework.Examples.ServiceInfo` exposes nested metadata classes for each service:
   ```csharp
   public static string Name => "MyService";
   public static string Lifetime => "Transient";
   public static global::System.Type Type => typeof(global::MyNamespace.MyService);
   ```
   Metadata is emitted by default and can be disabled.

## Features demonstrated

- Incremental pipeline with `IncrementalPipeline.ForAttributeWithMetadataName`.
- Attribute-data model (`GenerateServiceAttributeData`) generated by `AttributeDataModelGenerator` using `[Argument]` for a constructor parameter and `[Property]` for a named property.
- Enum string extraction from `TypedConstant` values (`IsEnum = true`).
- `CodeWriter` usage for all output, including post-initialization sources and attribute/enum declarations.
- `TypeValueObject` / `TypeLibrary` helpers for safe type/namespace references.
- Diagnostic reporting for invalid inputs (e.g. interfaces, static classes, nested classes, abstract classes).
- Generator disabling via MSBuild properties.
- Unit testing with `Purview.SourceGeneratorFramework.Testing`.

## Usage

```csharp
using Purview.SourceGeneratorFramework.Examples;
using Microsoft.Extensions.DependencyInjection;

namespace MyApp.Services;

[GenerateService(ServiceLifetime.Scoped, Name = "NamedService")]
public class OtherService { }

// In your startup code:
var services = new ServiceCollection();
services.AddExampleServices();
```

The generated registration will call `services.AddScoped<OtherService>()`.

## MSBuild properties

| Property | Description |
|----------|-------------|
| `ExampleGenerator.Disabled` | Set to `true` to disable `ServiceRegistrationGenerator` entirely. |
| `ExampleGenerator.EmitServiceInfo` | Set to `false` to suppress the `ServiceInfo` metadata class. |

Example in a project file:

```xml
<PropertyGroup>
  <ExampleGenerator.Disabled>true</ExampleGenerator.Disabled>
</PropertyGroup>
```
